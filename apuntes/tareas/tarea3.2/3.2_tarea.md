# **Tarea 3.2: Creación de usuarios y grupos**

### **Descripción de la tarea**

En esta práctica realizaremos la creación de diferentes usuarios y grupos y haremos uso de los principales comandos de Linux para su administración.

Salvo que se indique otra cosa, todos los usuarios tendrán su carpeta personal en `/home`, la shell `/bin/bash` y la contraseña `abc123.`.

### **Pasos de la tarea**

1. Crear los grupos sistemas, informatica y micro.
2. Crear el usuario1 con grupo principal informatica y sin shell, de modo que no pueda iniciar sesión.
3. Crear el usuario2 con una cuenta que caduque mañana. La fecha de mañana se debe calcular con el comando `date`, sin escribirla a mano.
4. Crear el usuario3 y hacer que en el primer inicio de sesión se le pida el cambio de contraseña. Al entrar con el usuario3, la nueva contraseña será, por ejemplo: `Password,319`.
5. Crear el usuario4 y, una vez creado, hacer que su cuenta caduque el 30/06/2027.
6. Crear el usuario5. Tiene que tener el alias de comando `listar`, que debe ser un `ls` con formato largo que ordene los ficheros por fecha de modificación. Además, tiene instalado Java en el directorio `/usr/local/jdk1.7` y tiene que tener definida la variable `JAVA_HOME`. Ambas cosas deben estar disponibles cada vez que el usuario inicie sesión. La instalación de Java se simulará creando ese directorio vacío.
7. Comprobar el correcto funcionamiento del usuario5.
8. Eliminar los usuarios y grupos creados.
